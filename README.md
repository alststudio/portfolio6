# PERLÉ — Hero Butik Rel Pakaian

Satu halaman hero toko gaun malam fiktif **PERLÉ** untuk portofolio ALSTSTUDIO:
ruangan butik bernuansa merah muda dengan rel rose-gold berisi dua belas gaun
satin dan tule di hanger kawat.

- Mengarahkan kursor (atau mengetuk) membuat gaun berputar menghadap ke depan,
  membesar, dan mendorong gaun tetangganya.
- Klik gaun membuka jendela produk: foto dipakai model atau di hanger, pilihan
  ukuran XS–XL, bahan & potongan, dan tombol "Masukkan ke tas".
- "Masukkan ke tas" menerbangkan gaun menyusut masuk ke tas belanja di ruangan;
  tas dan pil "TAS KAMU" membuka panel tas berisi daftar pilihan dan subtotal.
- Semua teks berbahasa Indonesia, harga dalam Rupiah. Gambar memakai URL proxy
  sesuai brief (tidak di-host ulang), dan sprite gaun dibersihkan di sisi klien
  (canvas) sebelum ditampilkan.
- Tampilan ponsel (< 820 px) memakai strip rel yang bisa digeser; mode gerak
  berkurang (`prefers-reduced-motion`) menonaktifkan animasi.

Live di https://alststudio.github.io/portfolio6/
